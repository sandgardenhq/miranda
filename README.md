# Miranda

Know exactly what your coding agents cost. Miranda meters every request and prices it against real per-model rates, attributed to the issue, project, model, and person that spent it — no estimates, every figure traces back to the run that incurred it.

This repository hosts the published Miranda plugin marketplace, serving Claude Code, Codex, and OpenCode. It is populated automatically by the `publish-miranda-marketplace.yml` workflow in [sandgardenhq/gloria.dev](https://github.com/sandgardenhq/gloria.dev) on merge to `main`.
